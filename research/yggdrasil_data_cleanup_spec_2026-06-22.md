## 1. HARD GATES (a doc must pass ALL to be eligible)

### Gate A — License (permissive only)
**KEEP** only files/repos/datasets whose license is one of:
`Apache-2.0, MIT, BSD-2-Clause, BSD-3-Clause, CC0-1.0, CC-BY-4.0 (with attribution preserved), Unlicense, ISC, MPL-2.0 (file-level only)`.
**DROP** everything else, including:
`GPL/AGPL/LGPL (any), CC-BY-NC, CC-BY-ND, CC-BY-SA (copyleft), proprietary, "no license" / missing LICENSE (= all-rights-reserved), unknown`.
- **GitHub (`02_github_code`):** resolve each repo's license from its `LICENSE`/`COPYING` file or SPDX header. **No LICENSE file ⇒ DROP** (default is all-rights-reserved, *not* public domain). Expect to drop the large majority of the 26 GB.
- **HF (`08_hf_volume`):** keep only datasets whose hub `license:` tag is in the whitelist. Unknown/NC/ND ⇒ DROP.
- Record the detected license + its source (file path / SPDX / hub tag) for every KEEP. No license evidence ⇒ DROP.

### Gate B — Provenance (no closed-model outputs)
- For `03_synthetic_agent_traces` and any "synthetic"/"distilled" shard: identify the **generator**.
  - Deterministic template / open-model generated ⇒ allowed (but see value note below).
  - Generated by **Claude / GPT / Gemini / any closed model** ⇒ **DROP** (ToS taint).
  - Generator unknown ⇒ DROP.

### Gate C — Eval decontamination
- Build an n-gram index of **every** eval benchmark Aurelius uses: HumanEval, HumanEval+, MBPP, MBPP+, LiveCodeBench, GSM8K, MATH (and the repo's gym F2/F3 + `eval_data/`).
- Remove any training doc with high overlap (recommended: **13-gram exact match**, or ≥50% line/solution overlap with any benchmark item).
- Emit a decontamination report (counts removed per benchmark). **Zero contamination is the acceptance bar.**

### Gate D — Dedup
- Exact (sha256) **and** near-dup (MinHash/LSH, e.g. Jaccard ≥ 0.8) dedup, within and across sources.

## 2. ZIP-FIT target-aligned selection (after the gates)
Even within the license-clean subset, most scraped web/code is off-distribution noise. Use **ZIP-FIT** to keep only what's
aligned with the model's target distribution.

- **Method (ZIP-FIT, Obbad et al. 2024 — gzip-ratio alignment for data selection; ~85% faster convergence, beats DSIR/D4 on code):**
  1. Build a small **target reference set `T`** = a curated sample of the **exact distribution we want the model good at**:
     clean **code** (MBPP/HumanEval-style functions, permissively-licensed), **math** (GSM8K/MATH-style), **reasoning** (clean CoT).
     Keep `T` small (a few MB per domain) and **license-clean** itself.
  2. For each candidate doc `d`, compute the **gzip alignment score** vs `T` — a normalized-compression-distance style metric:
     `NCD(d,T) = (C(d⊕T) − min(C(d),C(T))) / max(C(d),C(T))`, where `C(x)` = gzipped byte length. **Lower NCD = more aligned.**
  3. Rank candidates per domain by alignment; **keep the top-aligned fraction** per domain (tune to a target size).
- **Why it fits:** CPU-only (just gzip), no model needed — ideal for a 120 GB → clean-subset pass. It selects distributionally-on-target
  data and drops web noise *within* the already-license-clean pool.
- **Sizing:** continued-pretrain only needs **~1–20 B tokens** (memory: linear-in-tokens, ~25 M tok/A100-hr for 3B). Don't keep 100 GB
  because it's clean — keep the **top-aligned few GB** per domain. Quality + alignment > volume.

## 3. Output contract (what "done" looks like)
Emit JSONL shards in the repo's expected format, one record per doc:
```json
{"text": "...", "source": "<orig path/repo/url>", "license": "<SPDX>", "license_evidence": "<where found>",
 "provenance": "<scraped|open-synth>", "sha256": "...", "zipfit_score": <float>, "domain": "code|math|reasoning|prose"}
```
Plus a top-level `CLEANED_MANIFEST.json` with, per shard: license breakdown, dedup stats, **decontamination certificate**
(benchmarks checked + items removed), ZIP-FIT score distribution, total tokens. This is the **certificate-gated data** requirement —
no certificate, not eligible for training.

### Acceptance gates (all must hold)
- [ ] 100% permissive-licensed (manifest proves it; every KEEP has license_evidence)
- [ ] 0 eval contamination (decontamination report attached)
- [ ] deduped (exact + near-dup)
- [ ] ZIP-FIT-ranked, target-aligned, sized to a sane continued-pretrain budget (~1–20 B tok)
- [ ] no closed-model-generated content

## 4. After cleanup — the usage gate (important)
A clean corpus is **necessary, not sufficient**. Per the Aurelius roadmap, **do NOT train on it just because it exists.**
It becomes a **v1.x continued-pretrain layer only after a *confirmed knowledge gap*** that CPT actually fixes (measured on the
benchmark battery). Continued-pretrain is a **modest** lever; scraped/template data is **coverage, not capability ceiling**
(SFT/CPT can't beat a strong base on capability). Hand the cleaned corpus + manifest back; the decision to use it is gated downstream.

**Data-ordering note (verified 2026-06-22): if/when the cleaned corpus is used for continued-pretrain, order it via TREC** (`2509.25380`, "Predicting Training Re-evaluation Curves") — TRECs are predictable in advance from AdamW's EMA coefficients, and **placing the highest-quality data at the TREC minima** (where the model is most receptive) improves performance (validated 111M–3.9B, continual-pretrain). Pairs with the ZIP-FIT *selection* above: ZIP-FIT picks *which* data; TREC picks *when* to feed it.

## 5. One-line summary
**License-gate (permissive only, drop unlicensed/GPL GitHub + closed-model outputs) → decontaminate vs every eval → dedup →
ZIP-FIT gzip-alignment select toward the code/math/reasoning target → emit certificate-gated JSONL shards.**
Clean + aligned + certified, sized small. Then it waits for a confirmed need.
