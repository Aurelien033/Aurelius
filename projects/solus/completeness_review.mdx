## Intended Use

Solus-7B is an instruction-following language model for English-language
use-cases: chat, reasoning, code generation, and creative writing.
It is trained for commercial and non-commercial use under the Apache 2.0 license.

## Architecture

```
Embedding table (128K × 4096)
└── 32 × SolusDecoderBlock [pre-Norm → GQA attn → residual → pre-Norm → SwiGLU MLP → residual]
     · 32 query heads  · 7 KV heads  head_dim=128  kv_compression=4.57×
     · RMSNorm         · SiLU-gate
└── Final RMSNorm
└── LM Head (tied = Embedding.T) → vocab logits
```
