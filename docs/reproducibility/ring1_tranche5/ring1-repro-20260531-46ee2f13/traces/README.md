# Traces — regenerated run output, not committed

`test_split/sidecars/` holds the per-trace memory-event sidecars
(`<trace_id>_memory_events.ndjson`) written by the Ring 1 trace logger during this
tranche's run. They are bulk run output rather than source, and the repository
already declares them generated byproducts in `.gitignore`
(`*.ndjson` and `docs/reproducibility/**/*.ndjson`). The copies that had been
committed here were removed for that reason; the directory is kept so the
repro-pack layout still matches what the recipe produces.

Regenerate (from the repository root):

```bash
python scripts/ring1_trace_collector.py --config configs/ring1_tranche2.yaml --num_traces 100
python scripts/ring1_tranche5_workflow.py --config configs/ring1_tranche5.yaml
```

## What stays committed in this pack

The summary/report artifacts a reader actually needs to check the result — not the
per-trace bulk:

- `workflow_summary.json` (tranche result + ablation table)
- `gate_verification_report.json`
- `metrics/` — `aggregated_metrics.json`,
  `bootstrap_ci.json`, `raw_results.json`
- `dreambank_run/` — pre/post param hashes, DreamBank result, preferences
- `manifest.json`, `config/`, `code_hashes.txt`, `seeds/master_seeds.json`,
  `verification/verify.sh` inside `ring1-repro-20260531-46ee2f13/`
