# Evidence Manifest — M-17: BFF upstream auth headers only if service key set

## Row Metadata
- **Row ID**: M-17
- **Status**: FIXED

## Problem
`middle/src/provider_router.ts:251-254` only sent auth headers to upstream "if service key is set" — meaning requests could be made to the gateway without authentication when the key was misconfigured or unset. Inconsistent with C-01 (gateway now always requires API key).

## Fix
Changed to fail-closed: throw an error when `serviceApiKey` is missing, explaining the failure mode. Previously silently made unauthenticated calls.

## Files Modified
- `middle/src/provider_router.ts`: `completeWithAurelius()` now throws if no key configured
