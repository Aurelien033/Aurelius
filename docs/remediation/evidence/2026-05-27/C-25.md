# Evidence Manifest — C-25: BFF Streaming Is Real SSE Proxy

## Row Metadata
- **Row ID**: C-25
- **Previous status**: OPEN
- **New status**: FIXED

## Problem
`POST /api/chat/completions` with `stream: true` buffered the full upstream JSON completion, then re-emitted fake 5-character chunks with a 15ms delay. Upstream SSE was ignored.

## Changes

### `middle/src/routes/chat.ts`
- Added `pipeUpstreamSse()` — pipes upstream `ReadableStream` to the Express response via `Readable.fromWeb` + `pipeline`.
- Streaming path calls `provider.streamComplete()` instead of `provider.complete()`.

### `middle/src/provider_router.ts`
- Added `streamComplete()` — routes like `complete()` but returns raw upstream `Response`.
- Non-stream `complete()` now sends `stream: false` to upstream (no silent JSON buffer on stream requests).
- Mock backend emits a minimal valid SSE frame set locally (no upstream exists for mock).

### `gateway/aurelius_api.py`
- When `stream: true`, returns `StreamingResponse` with OpenAI-shaped SSE from `SSEChatStream`.
- Uses engine token streaming when available; otherwise emits generated text without artificial delay.
