# Evidence Manifest — M-14: ACAO * in legacy serving

## Row Metadata
- **Row ID**: M-14
- **Status**: FIXED

## Problem
`src/serving/aurelius_server.py:1088` sent `Access-Control-Allow-Origin: *` on SSE connections — wildcard CORS allows any origin to read the event stream (info disclosure + CSRF vector).

## Fix
Added `_cors_allowed_origin()` method that reads `CORS_ORIGINS` env var and only echoes back the origin if it's in the allow-list. If `CORS_ORIGINS` is unset, no ACAO header is sent — same-origin clients continue to work.

## Files Modified
- `src/serving/aurelius_server.py`: added `_cors_allowed_origin()` helper; replaced hardcoded `"*"` with origin-checked value; added `os` import; added `Vary: Origin` header
