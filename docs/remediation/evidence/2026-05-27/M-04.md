# Evidence Manifest — M-04: 50MB JSON body limit on BFF

## Row Metadata
- **Row ID**: M-04
- **Status**: FIXED

## Problem
`middle/src/server.ts:41` unconditionally accepted 50MB JSON bodies on every route — a DoS vector for all BFF routes.

## Fix
Lowered default to 10MB; made configurable via `BFF_JSON_BODY_LIMIT` env var for routes that need larger payloads (model fine-tuning, etc.).

## Files Modified
- `middle/src/server.ts`: configurable limit with 10MB default
