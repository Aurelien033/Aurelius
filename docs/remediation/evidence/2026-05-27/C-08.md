# Evidence Manifest — C-08: Scheduler Cron Missing API Key

## Row Metadata
- **Row ID**: C-08
- **Finding title**: Scheduler cron calls admin command without API key
- **Theme**: T4 — BFF scope matrix
- **Previous status**: OPEN
- **New status**: FIXED

## Reproduction Result
**Reproduced and fixed.** `scheduleTask()` fetched `/api/command` with only `Content-Type`, causing silent 401 against `requireAdmin` endpoint.

## Change
`middle/src/routes/scheduler.ts`:
```typescript
function commandRequestHeaders(): Record<string, string> {
  const headers: Record<string, string> = { 'Content-Type': 'application/json' }
  const apiKey = process.env.AURELIUS_API_KEY
  if (apiKey) {
    headers['X-API-Key'] = apiKey
  }
  return headers
}
```

Cron fetch now passes `X-API-Key` from `AURELIUS_API_KEY`.
