# Evidence Manifest — M-01: AMC Tier-2 tokens are hash bytes

## Row Metadata
- **Row ID**: M-01
- **Status**: FIXED (documentation)

## Problem
M-01 claimed "AMC Tier-2 tokens are hash bytes not model IDs" as a finding.

## Investigation
Verified in `src/memory/amc_tier2.py:231-239`: the `token_ids` stored in `AMCMemoryBlock.tokens` ARE intentionally blake2b-derived identity tokens used for cache routing within the memory runtime. They are NOT model vocab IDs and never get fed to `AureliusTransformer.forward()` or `nn.Embedding`.

The code was correct — the finding was actually a *documentation gap*, not a bug. The comment was ambiguous enough that an auditor could reasonably read this as "these token IDs will accidentally end up in the model's forward pass."

## Fix
Clarified the inline comment at lines 236-240 with explicit warning:
"These should never be fed to AureliusTransformer forward() or nn.Embedding directly."

## Files Modified
- `src/memory/amc_tier2.py`: clarified comment explaining identity-token semantics
