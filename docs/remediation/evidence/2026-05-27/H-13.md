# Evidence Manifest — H-13: Security audit covers AMC memory only

## Row Metadata
- **Row ID**: H-13
- **Status**: FIXED

## Problem
`tests/security/run_security_audit.py` only ran `AMCSecurityAudit` — adversarial memory attacks on AMC. No audit coverage for the broader code surface (eval/exec, pickle, torch.load, etc.).

## Fix
Created `tests/security/run_broad_security_audit.py` that aggregates:
1. Existing `AMCSecurityAudit` (in-tree adversarial tests)
2. Bandit static analysis (subprocess, optional)
3. Pattern scan across `src/`, `gateway/`, `tools/`, `agent/` for 9 common vulnerability patterns
   (hardcoded secrets, eval, exec, subprocess.shell=True, pickle.load, torch.load w/o weights_only, os.system, md5, yaml.load w/o Loader)

First run output (baseline snapshot):
- 2392 Python files scanned
- 315 pattern findings (mostly eval in training code — expected for research)
- Baseline preserved for tracking regressions
