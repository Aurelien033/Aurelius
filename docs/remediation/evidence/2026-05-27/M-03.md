# Evidence Manifest — M-03: _sanitize_completion Unicode

## Row Metadata
- **Row ID**: M-03
- **Status**: FIXED

## Problem
`_sanitize_completion()` in `gateway/aurelius_api.py` called `text.encode("ascii", "ignore")` which strips ALL non-Latin characters (CJK, emoji, Cyrillic, etc.). This corrupts model output for any multilingual generation.

## Fix
Replaced ASCII-only encoding with no-op encoding path. Whitespace normalization retained. Added `isinstance(text, str)` guard against non-string model output.

## Files Modified
- `gateway/aurelius_api.py`: `_sanitize_completion()` rewrite
