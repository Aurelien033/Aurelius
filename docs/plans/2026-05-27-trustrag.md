# TrustRAG — Quarantine-aware, trust-bound retrieval

> **For Hermes:** Implement inline, strict TDD. Do not push.

**Goal:** Build a retrieval controller whose output is governed by the
AMC trust/quarantine surfaces, so that retrieved context never silently
serves stale or revoked trust. Complements DreamBank (preference alignment)
and Federation (distributed trust propagation at scale) with a third
pillar: trust-gated retrieval.

**Architecture:** Pure-Python retrieval filter over an iterable of
`AMCMemoryBlock`. Quarantine-aware, trust-aware, contradiction-detecting.

## Claim / not-claimed

**Claim:**
- A retrieval controller built on trust-aware primitives enforces:
  - Quarantined blocks excluded from privileged retrieval
  - Revoked trust → new cache key (stale cache cannot serve)
  - Contradiction detection between same-token, different-provenance blocks
  - Bounded unverified inclusion (configurable cap)

**Not claimed:**
- Real embedding / dense-retrieval (we filter over an iterable, no vector similarity).
- Real semantic-contradiction detection (we use literal token equality as MVP stand-in).
- Real reranking (ordering is preserved from input iterable).

## API contract

```python
from src.memory.amc_runtime_cache import AMCMemoryBlock, TrustState

@dataclass(frozen=True)
class TrustRAGConfig:
    min_trust_level: TrustState = TrustState.UNVERIFIED
    max_unverified: int = 5                      # hard cap on UNVERIFIED blocks
    quarantine_excludes_retrieval: bool = True   # skip quarantined blocks
    detect_contradiction: bool = True            # flag same-tokens-diff-provenance pairs

@dataclass(frozen=True)
class TrustRAGResult:
    retrieved_ids: tuple[str, ...]
    trust_distribution: tuple[tuple[str, int], ...]  # sorted by TrustState.value
    contradiction_pairs: tuple[tuple[str, str], ...]  # (block_id_a, block_id_b)
    quarantine_ids: tuple[str, ...]
    revocation_flags: tuple[str, ...]          # ids with revocation_epoch > 0
    retrieved_tokens: tuple[tuple[int, ...], ...]

class TrustRAGController:
    def __init__(self, config: TrustRAGConfig | None = None): ...

    def retrieve(
        self,
        store: Iterable[AMCMemoryBlock],
        *,
        max_retrieve: int = 10,
    ) -> TrustRAGResult: ...
```

Invariants:
- Quarantined blocks NEVER appear in `retrieved_ids` when `quarantine_excludes_retrieval=True` (they DO appear in `quarantine_ids`).
- If `min_trust_level == VERIFIED`, only VERIFIED blocks appear in the result.
- `max_unverified` caps UNVERIFIED blocks regardless of max_retrieve.
- Identical-token blocks with differing provenance → in `contradiction_pairs`.
- Blocks with `revocation_epoch > 0` → in `revocation_flags`.
